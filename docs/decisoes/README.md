# Registros de decisões

Este diretório guarda decisões relevantes e duradouras. Uma decisão registra contexto, opções, escolha e consequências; não substitui Issue, tarefa ou documentação de código.

## Estados

- **Proposta:** em análise;
- **Aceita:** decisão vigente;
- **Substituída:** outra decisão passou a valer;
- **Rejeitada:** analisada e não adotada.

## Quando criar

Use para decisões como banco de dados, organização arquitetural, autenticação, estratégia de frontend, migrations, política de merge ou testes integrados. Não use para mudanças pequenas e reversíveis.

## Nome

```text
0001-titulo-curto.md
0002-outra-decisao.md
```
