## Regra de confiabilidade

Use as marcações `[CONFIRMADO]`, `[PROPOSTA]`, `[PENDENTE]` e `[DECISÃO]`. Uma proposta só se torna decisão depois de validação adequada. Quando o código e um documento divergirem sobre o estado atual, inspecione o repositório e corrija a documentação.

## Manutenção

Toda Pull Request deve responder: **esta alteração exige atualização da documentação?** Evite documentos vazios, links quebrados e datas manuais que perdem validade; use Issues, PRs e histórico Git como evidência.
